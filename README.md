# AIRA

An Android application that provides real-time emotional support through voice interaction and calming music. The app continuously listens for signs of distress in speech and responds with comforting voice messages and calming music.

## Features

- Continuous audio monitoring
- Real-time speech analysis for distress detection
- Voice responses using text-to-speech
- Calming music playback
- Works completely offline
- Minimal UI design

## Technical Requirements

- Android 8.0 (API level 26) or higher
- Kotlin
- Jetpack Compose for UI
- Android Studio Arctic Fox or newer

## Setup

1. Clone the repository:
```bash
git clone https://github.com/abi-raghavan/aira-core.git
```

2. Open the project in Android Studio

3. Sync the project with Gradle files

4. Build and run the project on your device or emulator

## Permissions

The app requires the following permissions:
- `RECORD_AUDIO`: For continuous voice monitoring
- `FOREGROUND_SERVICE`: For background operation
- `WAKE_LOCK`: To keep the device awake during operation
